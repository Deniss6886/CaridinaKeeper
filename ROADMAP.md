# Roadmap

## 0.1 – local-first preview

- [x] Tank, water, care, breeding, settings, backup, and CSV workflows.
- [x] Runtime validation, atomic restore, safe formula-neutralised CSV, PWA shell, responsive UI.
- [x] CI, Pages deployment, security policy, accessibility smoke coverage.

## 0.2 – evidence and provenance

- [ ] Versioned evidence records for species/line, life stage, source, method, calibration, and confidence.
- [ ] Water-batch records linking source water, remineralizer lot, recipe, and recipient tanks.
- [ ] Explicit raw EC versus derived TDS conversion metadata.
- [ ] More complete manual accessibility review and browser support matrix.

## 0.3 – integrations

- [ ] Read-only Home Assistant REST/WebSocket/MQTT import with entity allowlists, rate limits, and stale-data flags.
- [ ] Import preview, conflict handling, and migration tooling for a dedicated production origin.
- [ ] Optional self-hosted release artefacts and signed release metadata.

Actuation, diagnosis, and speculative genetics prediction are intentionally out of scope until a separate safety review proves otherwise.
