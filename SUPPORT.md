# Support

For usage questions, open a GitHub issue with:

- app version and browser/OS;
- whether the issue survives a reload;
- a minimal reproduction using fictional data (never attach a real backup publicly);
- console errors with secrets, tokens, and local paths removed.

For suspected security or privacy problems, use the private instructions in [SECURITY.md](SECURITY.md). For scientific disagreements, include the species/line, life stage, measurement method, units, source, and uncertainty; the project does not promise universal Caridina thresholds.
