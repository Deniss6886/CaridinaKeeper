# Changelog

## Unreleased

- Evidence provenance, water-batch traceability, read-only Home Assistant ingestion, and dedicated-origin migration tooling remain planned.

## 0.1.1 – 2026-09-12

- Enforced strict runtime validation, globally unique record IDs, relationship checks, transactional cascades, atomic target replacement, and calendar-correct recurring reminders.
- Hardened JSON backup restore with byte and structure limits, duplicate-member/prototype-pollution rejection, full referential validation, a confirmation preview, and rollback coverage for quota and write failures.
- Preserved locale, theme, and motion preferences when deleting user records; synchronized settings and data changes across tabs with IndexedDB live queries.
- Corrected target-range/unit evaluation, warning semantics, decimal-comma input, optional uncertainty, date handling, demo measurements, and safe CSV formula neutralisation.
- Added failure-safe forms, destructive-action confirmations, localized validation and status messages, a render fallback, responsive dialog fixes, and system theme/reduced-motion synchronization.
- Expanded the browser suite to complete unskipped desktop and mobile journeys, invalid-import preservation, confirmed demo/restore flows, reload persistence, and automated accessibility checks.
- Gated Pages deployment on the complete reusable CI and CodeQL workflows, tightened workflow permissions, pinned Actions, and upgraded React/React DOM together to 19.3.0.

## 0.1.0 – 2026-09-12

- Initial offline-first PWA shell, local IndexedDB data model, validated JSON backup, safe CSV export, responsive CRUD views, English/German localization, and demo workspace.
- Added unit, database, Playwright smoke, and axe accessibility checks.
- Added CI, Pages deployment, CodeQL, Dependabot, community-health files, research notes, and security documentation.
